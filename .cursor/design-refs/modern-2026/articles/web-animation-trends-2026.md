# Web Animation Trends 2026 (síntese)

Fonte: https://motionkit.io/blog/web-animation-trends-2026  
Baixado: 2026-11-08

## Headline

Scrollytelling, tipografia cinética, CSS scroll-driven nativo; performance (INP) e `prefers-reduced-motion` como filtro. Estilo vencedor: **restrito e proposital**.

## Top 10

1. Scrollytelling / pin+scrub (GSAP ScrollTrigger)
2. Kinetic & variable typography (SplitText + variable fonts)
3. Scroll-driven CSS (`animation-timeline`) — baseline browsers
4. Performance-first / INP-aware (`transform`/`opacity`)
5. Bento-grid reveals (stagger)
6. 3D/WebGL **seletivo**
7. Cursor & micro-interactions
8. Smooth scroll bem feito (sem hijack ruim)
9. SVG path / draw
10. Restraint + a11y

## O que está saindo

- Entrance autoplay em tudo
- Smooth scroll laggy
- Preloader decorativo
- Hero video pesado como default
- Motion que estraga INP

## Tooling

- CSS cobre ~80% dos efeitos simples
- GSAP 100% free (2025) para o ~20% complexo
- WordPress/visual builders à parte — no nosso lab: React + CSS + Motion + GSAP
