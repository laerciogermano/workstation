# Frontend anti-slop (obrigatório)

## 1. Ler antes de codar

1. **[DESIGN-SYSTEM.md](../../design-refs/DESIGN-SYSTEM.md)** — padrão (tokens, componentes, checklist)
2. Este arquivo
3. Refs brutas: [SOURCES.md](../../design-refs/SOURCES.md) → unslop / Anthropic / anti-ai-slop / templates / cookbook
4. Motion / tendência moderna (React): [modern-ui-motion](../modern-ui-motion/SKILL.md) → [MODERN-UI-MOTION.md](../../design-refs/modern-2026/MODERN-UI-MOTION.md)

## 2. Processo

1. Assunto → audiência → job → direção (default **Editorial Bold** do DS)
2. Usar CSS/tokens/componentes do DS §2–§4
3. Self-check do DS §8 / unslop (qualquer “sim” = corrigir)

## 3. Ban list rápida

Dark mint `#3ecf8e`, Instrument Serif italic, Inter/Geist default, purple gradient, cream+#D97757 por reflexo, pill/eyebrow, ícone em caixa arredondada, fade-up em tudo, em-dash retórico.

Copy: sem narração de IA (lede que explica a página, “cada card abre…”, footer de design system, CTA “Abrir” genérico) — regra `copy-sem-narracao-ia`.

## 4. Escape

Direção alternativa só com justificativa (DS §7) ou marca em `*/marca/`.
