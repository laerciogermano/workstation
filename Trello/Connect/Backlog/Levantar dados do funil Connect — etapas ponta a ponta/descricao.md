## Objetivo

Levantar, para cada etapa do **funil canônico Connect**, de onde sai o número, quem registra, em que frequência e o que conta como avanço — para montar planilha/KPI ponta a ponta.

## Funil (ordem)

1. Conexão
2. Mensagem
3. Resposta
4. E-mail
5. Orçamento
6. Ordem de compra
7. Pedido
8. Compra dos produtos
9. Nota fiscal
10. Boleto
11. Embala
12. Envia
13. Recebe
14. Cobrança (caso necessário)

## Por etapa (preencher)

Para **cada** etapa acima, registrar:

| Campo | O que anotar |
|---|---|
| **Métrica** | o que conta (qtd, valor, prazo…) |
| **Fonte** | LinkedIn / e-mail / portal / planilha / manual |
| **Responsável** | quem gera ou anota o dado |
| **Frequência** | diário / semanal / por evento |
| **Critério de avanço** | quando passa para a próxima etapa |
| **Lacuna** | o que ainda não medimos / como obter |
