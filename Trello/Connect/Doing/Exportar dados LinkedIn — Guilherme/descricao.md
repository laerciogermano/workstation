## Objetivo
Exportar os dados do LinkedIn desta conta (conexões / leads) e disponibilizar o arquivo.

## Como exportar
1. LinkedIn → Configurações e privacidade → Dados e privacidade → Obter uma cópia dos seus dados
2. Selecionar pelo menos: **Conexões** (e demais dados úteis de leads, se disponível)
3. Solicitar arquivo e baixar quando chegar o e-mail
4. Anexar o CSV/ZIP neste card (ou enviar para o time)

## Entrega
Arquivo de exportação LinkedIn anexado / entregue.
