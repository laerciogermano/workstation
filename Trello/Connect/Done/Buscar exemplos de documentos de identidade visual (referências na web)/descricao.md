## Objetivo
Reunir referências reais de documentos de identidade visual (brand guidelines / brand books) para inspirar a 2ª versão da Identidade Visual ConectX.

## Como será feito

### 1. Pesquisa
- Buscar na web por: brand guidelines PDF, brand book, manual de identidade visual, brand identity system
- Priorizar exemplos públicos e bem avaliados (tech, B2B, SaaS, e-commerce — próximos do contexto Conect)
- Filtrar por qualidade visual, clareza tipográfica, sistema de cores, uso de logo e tom de voz

### 2. Download
- Baixar apenas PDFs/documentos liberados para download (páginas oficiais das marcas, repositórios públicos, sites de design)
- Evitar material pago/protegido sem permissão
- Nomear arquivos de forma clara: `marca-ano-brand-guidelines.pdf`

### 3. Upload no card
- Anexar cada arquivo neste card (Trello attachments)
- Comentário curto por lote: fonte/URL de origem + por que serve de referência
- Meta inicial: pelo menos 5–8 documentos bons; mais se a qualidade justificar

### 4. Critério de Done
- Só mover para **Done** quando TODOS os PDFs/documentos baixados estiverem anexados neste card
- Checklist mental: pesquisa ok → downloads ok → anexos ok → comentário com fontes → Done

## Fora de escopo
- Não redesenhar a identidade Conect neste card
- Não editar/mesclar os PDFs — só coletar e anexar referências
