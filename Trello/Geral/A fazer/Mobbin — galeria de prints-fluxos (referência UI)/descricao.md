## Referência — Mobbin

Biblioteca de **prints e fluxos** de apps/web reais (onboarding, checkout, empty states, paywalls, etc.). Fonte padrão da workstation para pesquisar “como o app X faz a tela Y”.

- **URL:** https://mobbin.com/
- **Explore:** https://mobbin.com/explore
- **Categoria:** galeria de UI / telas e fluxos (mobile + web)
- **O que copiar:** padrões de fluxo, hierarquia de tela, empty/error/paywall, motion documentado
- **O que evitar:** copiar marca/layout literal; tratar print como prova de conversão
- **Acesso:** free limitado; Pro/Team desbloqueia biblioteca + MCP (`https://mobbin.com/mcp`)
