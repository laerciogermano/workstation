## Objetivo
Fazer **benchmarking de identidade visual** de apps e marcas relevantes para o **RoleGo** (descoberta de eventos / vida noturna / social), gerando insumos para evoluir a marca (v1 → v2) e o logo.

## Por quê
A v1 já existe ([card](https://trello.com/c/gU37I2lg)), mas falta um panorama de referências externas (cor, tipografia, logo, tom, UI dark/neon, apps de evento e social) para decidir o que manter, o que descartar e o que incorporar na v2 / logo.

## Escopo
Curadoria visual (prints + links + notas curtas) de:
- **Apps de eventos / ingresso** — Sympla, Eventbrite, Fever, Shotgun, Dice, Resident Advisor
- **Social / swipe / descoberta** — Instagram, Tinder, Bumble, Partiful
- **Vida noturna / lifestyle** — 3–5 marcas ou apps com identidade forte (dark, neon, nightlife)
- **Brand books** — 2–4 manuais públicos com estrutura boa para espelhar (capa, logo, cores, tipo, aplicações)

Para cada referência anotar: paleta, tipografia, logo, atmosfera, o que **levar** e o que **evitar** para o RoleGo.

## Insumos locais
- `role-go/identidade-visual.md` — tokens atuais
- `role-go/marca/` — manual v1 (HTML/PDF/ZIP)
- `role-go/input/rolego_mvp_completo_dark.pdf` — wireframes
- `role-go/input/rolego_slides_publico.pdf` — slides
- Cards: [identidade v1](https://trello.com/c/gU37I2lg) · [logo](https://trello.com/c/S7jWwUbC) · [v2](https://trello.com/c/Taaxly1i)

## Entrega
- Pasta `role-go/marca/benchmarking-identidade/` com curadoria (HTML e/ou PDF) + prints principais
- Anexos neste card (curadoria + prints)
- Comentário com **ranking** (top referências) e padrões a levar / evitar
- Atualizar `marca/README.md` com link deste card

## Critérios de aceite
- [ ] ≥ 8 referências documentadas (app ou marca)
- [ ] Prints anexados no card
- [ ] Ranking priorizado + lista “levar / evitar”
- [ ] Pasta local espelhada com card ID e URL
