## Objetivo
Identificar **todos os passos, ponto a ponto**, do fluxo completo: prospecção → criação de conta → LinkedIn → venda.

## Responsável
Marcelo

## Escopo
Documentar a jornada ponta a ponta, sem pular etapa. Incluir no mínimo:

1. **Prospecção** — como achar / filtrar / qualificar leads
2. **Criação de conta** — setup (persona, e-mail, perfil, fingerprint/IP se aplicável)
3. **LinkedIn** — onboarding, perfil, conexão, mensagem, follow-up
4. **Pipeline até a venda** — qualificação, proposta, fechamento, pós-venda

Para cada passo: o que é feito, quem faz, ferramenta/artefato, critério de “pronto” e o que vem depois.

## Critério de pronto
- [ ] Lista ordenada de todos os passos (sem buracos entre prospecção e venda)
- [ ] Cada passo com responsável, entrada, saída e ferramenta
- [ ] Lacunas / ambiguidades marcadas para decidir depois
