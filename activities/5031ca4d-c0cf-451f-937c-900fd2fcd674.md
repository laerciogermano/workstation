Criar visualização flow view uma lib que recebe uma arvore e visualiza o fluxo de forma visual, seguindo os conceitos do 
flow-oriented-programming.com

Regras
- nao possui interacao por equanto
- objetivo vai ser apenas montar a visualizacao por meio da arvore
- deve ter testea automatizados
- deve ser performatico e futuramente ter lazy loading

## Projeto criado

**Flow View** (`@flow/view`): [`flow-component/flow-view/`](../flow-component/flow-view/README.md)

Recebe uma árvore e desenha o fluxo na notação do [flow-oriented-programming.com](https://flow-oriented-programming.com/). Não altera a vista interativa antiga (`flow-component/src/view/`).

```bash
cd flow-component/flow-view
npm install
npm run demo      # http://localhost:5290/example/
npm run verify    # typecheck + testes + Chrome
```

```ts
mountFlow(elemento, {
  name: 'main',
  children: [
    { name: 'receber', out: ['pedido'] },
    { name: 'cobrar', in: ['pedido'], out: ['pagamento'] },
    { type: 'if', label: 'pago', children: [{ name: 'enviar', in: ['pagamento'] }] },
    { type: 'else', children: [{ name: 'avisar' }] },
  ],
});
```

### Regras

| Regra | Situação |
|-------|----------|
| Sem interação | Sem edição. Depois entraram, a pedido, só ações de visualização: zoom, deslocamento e minimizar |
| Montar a visualização por uma árvore | Feito |
| Testes automatizados | 69 testes e um roteiro no Chrome |
| Desempenho | Desenha só o que está à vista; testado com 20 mil funções |
| Lazy loading | Ainda não feito (era para o futuro) |

### O que tem

- [x] Passos sequenciais e paralelos, `if`/`else`, `switch`, laços e `try`/`catch`
- [x] Dados, objetos com campos, estado por passo e função abstrata
- [x] Responsável por função: arquivo, pessoa, IA, máquina ou objeto
- [x] Zoom de 10% a 300% e arrastar para mover
- [x] Minimizar uma função, minimizar tudo e expandir tudo
- [x] Tema escuro e claro, com as fontes IBM Plex incluídas
- [x] Exemplos dos conceitos, casos reais ilustrativos e um fluxo de 20 mil funções
