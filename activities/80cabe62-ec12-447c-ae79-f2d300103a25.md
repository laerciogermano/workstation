## Projeto criado

**Flow Editor** (`@flow/editor`): [`flow-component/flow-editor/`](../flow-component/flow-editor/README.md), sobre o Flow View.

```bash
cd flow-component/flow-editor
npm install
npm run app       # http://localhost:5295/app/
npm run verify    # typecheck + testes + Chrome
```
