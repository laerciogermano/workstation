# Timeline de prompts — Agent Shop

**Por quê:** guardar cada prompt usado neste projeto, na ordem.  
**Importante:** esteira e conversa com a IA ficam rastreáveis.  
**No fluxo:** todo prompt novo entra **primeiro** aqui e só depois o restante do trabalho.

Índice: [`timeline.md`](timeline.md).  
Visão: [`../README.md`](../README.md).  
Regras: [`../config/config-ia.md`](../config/config-ia.md).

## Como registrar

1. Copiar o texto **integral** do pedido.
2. Criar `NNN-AAAA-MM-DD-slug.md`.
3. Linha em [`timeline.md`](timeline.md).
4. Metadados, original, interpretação, o que foi feito.
