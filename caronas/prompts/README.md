# Timeline de prompts — Caronas

**Por quê:** guardar cada prompt usado neste projeto, na ordem em que aconteceu.  
**Importante:** a esteira de produto e a conversa com a IA ficam rastreáveis; ninguém depende da memória do chat.  
**No fluxo:** todo prompt novo entra **primeiro** aqui (arquivo numerado + linha na timeline) e só depois o restante do trabalho.

Índice cronológico: [`timeline.md`](timeline.md).  
Visão do produto: [`../README.md`](../README.md).  
Regras da IA: [`../config/config-ia.md`](../config/config-ia.md).

## Como registrar um prompt

1. Copiar o texto **integral** do pedido (sem corrigir digitação).
2. Criar o próximo arquivo `NNN-AAAA-MM-DD-slug.md` nesta pasta.
3. Acrescentar uma linha no topo da tabela em [`timeline.md`](timeline.md) (mais recente embaixo, ordem crescente de `NNN`).
4. Preencher metadados, prompt original, interpretação e o que foi feito.

Não resumir no lugar do original. O resumo vive só na timeline; o arquivo guarda o prompt completo.
