## Original

Crie um novo projeto e adicione um documento de visão. Esse projeto vai ser um client CDP, que o cliente vai instalar, ele precisa funcionar tanto no Linux, no Mac como no Windows, então precisa ser uma tecnologia que funcione pra todas. Ele vai de alguma forma funcionar em background, toda vez que a máquina ligar, esse client ele vai se conectar a um WebSocket, a um host ali configurado. E, uma vez que ele executado, ele instala em background e fica conectado sempre que a máquina ligar. Crie um documento de visão e crie posteriormente um plano de implementação pra isso.

## Interpretação

- Novo projeto no workspace (não estender só Gestão de CDPs).
- Produto = agente instalável no desktop do cliente (edge).
- Requisitos: Linux + macOS + Windows; background; install na 1ª execução; reconnect no boot; WebSocket para host configurável.
- Entregáveis pedidos: visão + plano de implementação.
