# Clozzy — apresentação “O Clozzy chega em breve”

Apresentação de 9 páginas (+ capa alternativa na pág. 2) com a mensagem: fomos a primeira plataforma de close friends pago e o Clozzy chega em breve (não “estamos de volta”).
Usa a identidade [identidade-verde-letras-redondas](../identidade-verde-letras-redondas/README.md) (importa o gerador dela).

1. Capa · O Clozzy chega em breve (painel branco, estrela e arco rosa, nome preto)
   - Capa alternativa (pág. 2): mesma capa com o arco preto
2. Fomos os primeiros
3. Por que agora
4. Marca nova, mesma essência
5. Como funciona
6. Para criadoras (roxo)
7. Para fãs
8. O lançamento nas redes (5 peças de lançamento)
9. Fecho · Chegamos em breve

```bash
cd clozzy/marca/apresentacao-em-breve && python3 _build.py
```
