1. Resumo executivo

  • Âncora Clozzy: rival doméstico #1 — Pix-first, discovery interna forte (Destaques / Em alta / Top Creators), carteira com bônus.
  • Produto: fan ↔ creator com assinatura (R$ 19,90–200), post avulso, chat, mimo, videochamada 1:1, live, afiliados.
  • App: não há store app; mobile = web + “Adicionar à tela inicial”.
  • IA: só política de perfil IA no Help — zero tools nativos tipo Fanvue.
  • Gap Clozzy: empate em rails BR; diferenciar em pack=produto + (opcional) suite IA com disclosure.

3. Inventário de funcionalidades

Cadastro / acesso

  • Toggle Seja assinante / Seja creator no signup
  • E-mail + senha (8+, maiúsc/minúsc, número, especial) com checklist visual
  • OAuth: Google, X, Apple, TikTok
  • Age gate 18+ + Termos / Privacidade
  • Confirmação de e-mail obrigatória; reenvio com cooldown 5 min
  • Login Email/CPF + senha; “Esqueceu sua senha?”
  • Onboarding pós-login (tutorial Destaques / carteira)

Discovery (fan logado)

  • Tabs Destaques / Top Creators
  • Em alta (rankings semanais)
  • Campanhas (ex.: Black Privacy + bônus carteira até R$ 1.000)
  • Top creators por região · Busca · Feed · cards de perfil
  • Ranking Free (perfis gratuitos)

Fan / monetização

  • Assinatura; prévia antes de assinar; gestão (trocar pagamento, antecipar, reativar)
  • Pagamentos BR + Apple Pay / Google Pay
  • Carteira (recarga, bônus)
  • Post avulso (compra sem assinatura via link)
  • Chat · Notificações · Mimo · Videochamada 1:1 · Áudios Feed/Chat · Amigos
  • Cancelamento / estorno (help)

Creator (help + blog — KYC não rodado)

  • Onboarding: país, CPF, nome, nascimento, telefone → foto/capa/bio/@ → redes → preço → doc + selfie (Certta)
  • Posts grátis/pagos; agendamento; editar/excluir; post avulso
  • Status (Online / Offline / No Chat); Restringir / Silenciar
  • Carteira / saldo / extrato / saque; % repasse; indicação; afiliados; CNPJ
  • Live + notificações aos assinantes; proteção / DMCA / denúncia

“App”

Sem app nativo nas stores. Mobile = web responsiva + atalho tela inicial (iOS Safari / Android Chrome).

Bottom nav observada: Feed · Em alta · Chat · Busca (+ home, notifications, user menu).

10. Implicações Clozzy

  • Empatar em Pix, carteira, discovery e assinatura+avulso.
  • Diferenciar com pack=produto (vitrine → compra → biblioteca) mais clara que feed OF-like.
  • Oportunidade IA: Privacy não compete em suite; Clozzy pode entrar com tools + disclosure (sem clonar Fanvue).
  • Mobile-first: Privacy vive de PWA — Clozzy deve priorizar web mobile excelente antes de app store.
  • Pendente inspeção: fluxo creator completo (KYC), checkout Pix real, live, videochamada, painel saque.
