# Privacy — inventário de funcionalidades

Fonte: inspeção CDP (2026-11-09) + [Central de ajuda](https://privacy.com.br/help/pt) + [guia blog](https://blog.privacy.com.br/guia-de-funcionalidades-da-privacy-que-todo-creator-precisa-conhecer/).

## Cadastro / acesso

- Conta **assinante** vs **creator** (toggle no signup)
- E-mail + senha (regras: 8+, maiúsc/minúsc, número, especial)
- OAuth: Google, X, Apple, TikTok
- Age gate 18+ + aceite Termos/Privacidade
- Confirmação de e-mail obrigatória (“Ativar minha conta”)
- Login Email/CPF + senha; “Esqueceu sua senha?”
- Toast reenvio de confirmação (cooldown 5 min)
- Onboarding pós-login (tutorial Destaques / carteira)

## Descoberta (fan logado)

- **Destaques** / **Top Creators**
- **Em alta** (rankings semanais)
- Promoções / campanhas (ex.: Black Privacy + bônus carteira)
- Top creators por região
- Busca
- Feed
- Cards de perfil criador (preview → assinar)

## Fan / assinante

- Assinar perfil (prévia antes de assinar — help)
- Métodos de pagamento BR + Apple Pay / Google Pay
- Carteira (recarga, bônus)
- Gestão de assinaturas (trocar pagamento, antecipar, reativar)
- Chat / mensagens
- Notificações
- Mimo (tip)
- Videochamada 1:1
- Áudios no Feed e no Chat
- Amigos / impulsionar perfil
- Cancelamento / estorno (help)
- Ranking Free (descoberta de perfis gratuitos)
- Post avulso (compra sem assinatura, via link)

## Creator (help + blog; KYC não executado nesta sessão)

- Seja creator → dados (país, CPF, nome, nascimento, telefone)
- Foto perfil / capa / bio / nickname / redes
- Preço assinatura R$ 19,90–200 + descontos tri/semestral
- Validação documento + selfie (Certta)
- Publicações grátis / pagas; agendamento; editar/excluir
- Post avulso (link de venda)
- Status personalizado (Online / Offline / No Chat)
- Restringir / Silenciar
- Carteira / saldo / extrato / saque (1º saque + internacionais)
- % repasse criador; link indicação; afiliados; CNPJ
- Live + notificações push-like aos assinantes
- Proteção de conteúdo / DMCA / denúncia

## App (“app”)

- **Sem app nativo** (confirmado help + blog)
- Mobile web + atalho tela inicial (iOS Safari / Android Chrome)
- Bottom nav observada: Feed · Em alta · Chat · Busca (+ home, notifications, user menu)
