# Clozzy — Limão + rosa + roxo + preto + branco (estudo de variações)

As cinco cores juntas: **verde-limão, Pink Deep, roxo, preto e branco**. São seis jeitos de dividir os papéis entre elas, variando também o tom do limão (claro ou ácido) e do roxo (o de hoje, elétrico ou lilás). Vem depois dos estudos [verde close](../identidade-verde-close/README.md) e [alternativas para o roxo](../alternativas-roxo/README.md).

| Arquivo | O que é |
|---|---|
| [`limao-rosa-roxo.pdf`](limao-rosa-roxo.pdf) · `.html` | O estudo, 18 páginas |
| `svg/` | Símbolo e logo de cada variação em cada superfície (72 arquivos) |
| [`_build.py`](_build.py) | Gerador. Reaproveita `../alternativas-roxo/_build.py` |

## Tons

Limão `#E8FF6B` · Limão ácido `#C8FF2E` · Roxo `#7C48C4` · Roxo elétrico `#7B3FF2` · Lilás `#C9B6FF` · Pink Deep `#E0005A`

## As variações

| | Variação | Papéis |
|---|---|---|
| A | **Limão destaque** | Rosa = marca e compra · roxo = criadora · limão = selo, sticker e close. **Recomendação para começar** |
| B | **Roxo + limão** | Roxo nos momentos de marca, com título e botão em limão; rosa só na compra |
| C | Limão protagonista | Anel limão no preto; rosa na compra; roxo na criadora |
| D | **Lilás + limão** | Roxo clareado para lilás (texto preto) + limão no close |
| E | Roxo elétrico + limão ácido | Os dois saturados; para campanha |
| F | Roxo é o close | Rosa = marca · limão = criadora · roxo = selo, anel ativo e trancado |

## Regras

- Continuam valendo: nada preto no rosa; rosa e roxo nunca encostados (1,2:1, vibram).
- Limão lê sobre o roxo (5,3:1) e convive com o rosa (4,4:1). No roxo, o destaque é limão, nunca rosa.
- Limão e lilás levam texto preto. Branco no limão não lê (1,1:1).
