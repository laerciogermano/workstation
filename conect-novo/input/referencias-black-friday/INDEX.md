# Referências Black Friday — insumos para contexto de IA

Pasta com tendências de mercado, boas práticas B2B/e-com, skills e prompts para planejar campanha BF (foco ConectMax: tech B2B, margem ~25%, ↑ faturamento). Preferir **Markdown**; `raw-html/` e PDF são backup bruto.

## Como a IA deve usar

1. Ler `research-local-black-friday.md` (síntese)
2. Aplicar `prompts/conectmax-bf-b2b-campanha.md` + skill `promotion-plan`
3. Completar com artigos B2B em `texto-extraido/` e sequências em `black-friday-emails`
4. Validar margem: nunca sugerir desconto sem conta de contribuição
