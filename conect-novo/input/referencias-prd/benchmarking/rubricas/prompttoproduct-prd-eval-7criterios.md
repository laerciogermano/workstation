# Rubrica PromptToProduct — PRD Eval (7 critérios × 1–5)

Fonte extraída de: https://prompttoproduct.substack.com/p/writing-prds-in-the-age-of-ai-i-tested  
Uso direto no benchmarking de outputs de skills/prompts.

## Prompt juiz

```
## Role
You are evaluating the following written text using a provided rubric.

## Evaluation Instructions
1. Paste the PRD to be evaluated.
2. Skim for context: product, user problem, structure.
3. For each criterion: score 1–5 (or N/A + justification);
   Strength (1); Suggestion (1 actionable); Rationale (brief).
4. Total out of 35.
5. Top 5 prioritized recommendations to improve the PRD.

## Method
Briefly describe the AI tool / skill / prompt used to generate the PRD.
```

## Critérios

| # | Critério | Pergunta |
|---|----------|----------|
| 1 | Clarity & Simplicity | Ideias centrais claras e concisas? Propósito fácil de captar? |
| 2 | User Understanding | Entendimento profundo dos usuários e necessidades? |
| 3 | Product Differentiation | Fica claro o que diferencia vs alternativas? |
| 4 | Risk Awareness | Riscos técnicos/usuário/mercado e assumptions? |
| 5 | Goal Alignment | Goals alinhados a outcomes reais (não vanity)? |
| 6 | Strategic Awareness | Mercado, competição, estratégia de longo prazo? |
| 7 | Functional Usability | Acionável para design, eng e stakeholders sem explicação extra? |
