3. Padrões a levar para o Connect

  • Tokens: cor semântica (brand/ok/err/stone), radius 12–16px, sombra suave, spacing modular 4/8
  • Tipografia: sans geométrica + mono para dados (já alinhado à v1: Plus Jakarta / JetBrains Mono)
  • Web: sidebar + content, cards de métrica, tables com badge/status, filtros chip, empty states
  • Mobile: bottom nav / sheets, listas densas, CTAs full-width, safe areas, dark mode nativo
  • Estética: menos “card pesado”, mais superfície plana + hierarquia tipográfica (Linear/Vercel/shadcn)
  • Evitar: glassmorphism exagerado e roxo genérico — usar azul Connect (#2563EB) como âncora
