# Benchmarking UI (web + mobile)

Curadoria visual para o design system Connect — prints 1440×900 + HTML/PDF.

- **Card Trello:** https://trello.com/c/C51LKW10/84-benchmarking-de-componentes-ui-web-mobile
- **Entrada:** `00-curadoria.html` / `00-curadoria.pdf`
- **Como regenerar prints:** Chrome headless `--window-size=1440,900 --screenshot=… URL`
- **Upload:** API Trello `POST /1/cards/{id}/attachments` (multipart `file`)
