# Logos ConectMax

Propostas de logo (3 direções) a partir do banner e dos prints do site.

- **Apresentação:** [`apresentacao-logos.html`](apresentacao-logos.html)
- **Card Trello:** https://trello.com/c/eMpli7k5
- **Paleta:** azul `#0077A9`, navy `#0A2A5C`, preto `#0A0A0A`, branco `#FFFFFF`

## Direções

| Pasta | Ideia | Preferência |
|-------|-------|-------------|
| [`A-rede-globo/`](A-rede-globo/) | Evolução do globo wireframe atual | recomendada |
| [`B-malha-nos/`](B-malha-nos/) | Rede densa de nós em círculo | alternativa |
| [`C-orbita-hex/`](C-orbita-hex/) | Globo + hex/órbitas (motivo do site) | alternativa |

Em cada pasta: `simbolo-{color,azul,white,mono}.svg`, `logo-completo-{color,white,mono}.svg`, `wordmark-{color,white,mono}.svg`.

## Ver

Abrir `apresentacao-logos.html` no browser (arquivos SVG relativos).

## Rollback

```bash
rm -rf marca/logos
```

Voltar o card Trello à descrição anterior (só brief) e remover anexos novos da entrega.
