# Checklist — perfil LinkedIn de vendedor B2B

**Uso:** critério must / should / nice para montar os perfis dos nossos vendedores.  
**Princípio:** o perfil é **landing page para o comprador**, não currículo para recrutador.

---

## Must (sem isso o perfil parece incompleto / pouco confiável)

| # | Elemento | Critério de pronto |
|---|----------|--------------------|
| 1 | **Foto** | Headshot recente, rosto ~60% do quadro, fundo neutro, roupa de trabalho, expressão acessível. Mín. 400×400. |
| 2 | **Banner / capa** | 1584×396. Marca + proposta de valor ou prova social — **não** paisagem/stock genérico. |
| 3 | **Headline** | Orientada ao prospecto: *quem ajuda + resultado* (cargo da empresa no fim, se precisar). ≤220 chars; primeiros ~45 chars carregam o gancho. |
| 4 | **Sobre** | Preenchido (não 1 linha). 1ª pessoa. Hook nas 1ªs ~3 linhas (antes de “ver mais”) + CTA no fim. |
| 5 | **Experiência atual** | Cargo + empresa + descrição com **resultados para o cliente**, não lista de tarefas internas. |
| 6 | **URL customizada** | `linkedin.com/in/nome-sobrenome` (sem string aleatória). |
| 7 | **Perfil público** | Visível para quem não está logado / rede ampla. |
| 8 | **Localização** | Cidade/região coerente com a operação comercial. |

## Should (levanta aceite de conexão e resposta)

| # | Elemento | Critério de pronto |
|---|----------|--------------------|
| 9 | **Featured / Destaques** | 2–4 itens: case, one-pager, post forte, link de conversa/agendamento, PDF institucional. |
| 10 | **Skills** | ≥5 relevantes ao comprador (não só ferramentas internas). Fixar top 5 alinhadas ao ICP. |
| 11 | **Contato** | E-mail corporativo (e canal secundário se houver) na info de contato. |
| 12 | **Atividade recente** | Algum sinal vivo (post/comentário) nas últimas 1–2 semanas — perfil zerado parece bot/inativo. |
| 13 | **Mídia na experiência** | ≥1 asset (case, apresentação, print de resultado) no cargo atual. |
| 14 | **Open to work** | **Desligado** em perfis de vendedor ativo (sinal errado para o comprador). |

## Nice (credibilidade extra / escala)

| # | Elemento | Critério de pronto |
|---|----------|--------------------|
| 15 | **Recomendações** | 3+ com resultado concreto (cliente ou colega). |
| 16 | **Formação** | Completa se reforça credibilidade; omitir se fraca/irrelevante. |
| 17 | **Certificações** | Só as que o ICP reconhece. |
| 18 | **Creator / hashtags** | Só se houver cadência real de conteúdo. |
| 19 | **Pronúncia do nome** | Opcional; útil em nomes ambíguos. |
| 20 | **Serviços (Service Page)** | Avaliar só se o modelo for consultivo/individual. |

---

## Anti-padrões (não colocar)

- Headline só com cargo (“SDR / AE / Vendedor na Empresa X”)
- Sobre vazio, em 3ª pessoa corporativa, ou “apaixonado por vendas”
- Banner skyline / stock / default LinkedIn
- Foto de festa, selfie distante, óculos escuros, filtro pesado
- Experiência só com deveres internos (“responsável por…”, “gestão de pipeline”)
- Featured vazio ou só post viral sem utilidade para o ICP
- Open to work / “buscando oportunidades” em conta comercial
- Skills aleatórias / buzzwords (ninja, rockstar, sinergia)
- Atividade zero por semanas após criação (perfil “morto”)

---

## Ordem de preenchimento (setup)

1. Foto + banner  
2. Headline + localização + URL  
3. Sobre (hook + ICP + prova + CTA)  
4. Experiência atual (+ mídia)  
5. Featured  
6. Skills top 5  
7. Contato + perfil público  
8. 1ª atividade (comentário ou post leve)  
9. Pedir recomendações (quando houver base)

**Auditoria inicial:** 60–90 min. **Refresh:** trimestral (15 min) — headline/métrica, Featured, exemplos no Sobre.
