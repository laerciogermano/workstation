## Layout de cada task

- `anexos/` — arquivos do card
- `links/` — URLs (cards fonte / anexos-link)
- `comentarios/` — comentários do card
- `manifest.json` — inventário
- `card-description.md` — descrição do card
- `README.md` — origem e como limpar

## Rollback

```bash
rm -rf tasks/<CARD_ID>
```
