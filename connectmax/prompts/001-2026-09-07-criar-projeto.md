## Prompt original

```
Adicione novo projeto chamado ConnectMax. Dentro desse projeto, adicione o Redmi, Redmi. Que explica o que que é o projeto. O projeto basicamente trata de uma forma de, otimização de automação. ```
```

## Interpretação

Criar, no workstation, uma pasta de projeto **ConnectMax**, com **README** de visão (pedido “Redmi” = README). O produto é **otimização e automação da prospecção via LinkedIn**. Contexto da unidade: **cinco vendedores**, faturamento médio mensal de **R$ 200 mil**; outros franqueados tiram cerca de **R$ 600 mil/mês** por terem mais vendedores. Toda a prospecção atual é no LinkedIn; automatizar esse processo permite **adicionar vendedores**, **subir o faturamento** e tornar a operação **fonte de renda para novos investidores**. Seguir o padrão dos outros projetos (visão, docs, config IA, timeline de prompts) e registrar este prompt.
