# Prompt 066 — Pastas tasks no padrão task-xx-titulo

**Data:** 2026-09-19  
**Projeto:** core/processo · screen-robot

## Prompt

```
o nome das pastas de tasks devem ter os ids task-xx-titulo
```

## Interpretação

Pastas em `tasks/` no formato `task-<nn>-<titulo>` (ex.: `task-002-subir-e-conectar`); branch homônima.

## Resultado

- Processo e [`screen-robot/tasks/`](../screen-robot/tasks/README.md) renomeados para `task-001-…` … `task-004-…`.
