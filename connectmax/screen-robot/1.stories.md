# Stories — screen-robot

**Por quê:** lista visual das histórias (US) e como cada uma funciona.  
**Detalhe:** [`2.scenarios.md`](2.scenarios.md) · **Visão do produto:** [`README.md`](README.md).

## Histórias

| ID | Estória | Como funciona |
|----|---------|---------------|
| US-01 | Provisionar um agente | Sobe/conecta o Android; só conclui com serial ADB `device` e boot completo (`sys.boot_completed` ou equivalente). Sem isso, nenhuma operação seguinte roda. |
| US-02 | Evento de boot | Após serial online, listener (com timeout) espera o sinal de boot; devolve “boot ok” como pré-condição para instalar/abrir apps. |
| US-03 | Evento de app aberta | Recebe package (e activity opcional) e espera a app em foreground antes de gestos/estabilidade — evita operar tela errada. |
| US-04 | Evento de tela estável | Com app em foreground, espera fim de transição de UI; libera screenshot, extração e operações confiáveis. |
| US-05 | Evento de mudança de dump | Compara dump atual com o anterior; quando a árvore UI muda, devolve dump atualizado (sem polling cego de screenshot). |
| US-06 | Instalar APKs | Para cada app em `device.config.json`, lê package/versão, baixa APK/XAPK e instala via `adb install` (ou equivalente). |
| US-07 | Abrir aplicativo | Launch de package/activity no device até a app em foreground; entrada para tap/type/scroll/print. |
| US-08 | tap | Toque em x,y ou bounds; espera a UI refletir a ação. |
| US-09 | type | Injeta texto (campo focado ou coords); estado esperado: texto na UI / aceito pelo campo. |
| US-10 | scroll | Swipe/scroll por direção, distância ou bounds; revela conteúdo fora da viewport. |
| US-11 | screenshot | Captura o frame e grava no path; alimenta visão (US-12), extração (US-13..16) e evidência. |
| US-12 | Resgatar coordenadas x,y a partir de uma imagem | Match de template no frame/tela; devolve x,y e confiança para alvos sem id estável no dump. |
| US-13 | Extrair árvore DOM | Fase 1: extrai textos → árvore só com textos; em seguida ícones/listas/imagens → árvore completa. Saída: árvore de componentes. |
| US-14 | Extrair ícones | Reconhece ícones (bounds, metadados) e devolve árvore de componentes contendo os ícones. |
| US-15 | Extrair listas | Identifica listas e itens; devolve árvore de componentes contendo as listas. |
| US-16 | Extrair imagens | Detecta imagens/fotos (bounds, metadados); devolve árvore de componentes contendo as imagens. |
| US-17 | Salvar sessão | Serializa estado em memória e grava no path da sessão. |
| US-18 | Remover sessão | Apaga arquivo de sessão e limpa contexto no runtime. |
| US-19 | Recuperar sessão | Lê o arquivo e reaplica device, apps, etapa e paths no runtime. |
