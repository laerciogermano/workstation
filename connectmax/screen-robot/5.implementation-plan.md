## EP-01 — Provisionar agente

### US-01 — Provisionar um agente

| Campo | Plano |
|-------|--------|
| API | `provisionAgent(cfg) → { serial, kind, provisionedAt }` |
| SC | SC-01 start runtime · SC-02 `adb connect` / `wait-for-device` · SC-03 `getprop sys.boot_completed` |
| Passos | 1) Ler `provision.serial` / `device`. 2) Se TCP, `adb connect`. 3) Loop até `device` + boot=`1` ou timeout. 4) Retornar serial pronto. |
| Gap | Separar start do container/AVD (scripts redroid/studio) da API Node; hoje só conecta/aguarda. Expor `startAgent` opcional que chama script de start. |
| Aceite | [`4.bdds.md`](4.bdds.md#us-01--provisionar-um-agente) |

## EP-02 — Eventos de UI

### US-02 — Evento de boot

| Campo | Plano |
|-------|--------|
| API | `waitForBoot(serial, { timeoutMs, onEvent }) → { boot: true }` |
| SC | SC-04 poll `sys.boot_completed` + callback `type: "boot"` |
| Passos | Extrair poll de boot de `provisionAgent`; emitir eventos; timeout configurável. |
| Gap | Lógica embutida em provision; falta API dedicada e `onEvent`. |
| Aceite | [`4.bdds.md`](4.bdds.md#us-02--evento-de-boot) |

### US-03 — Evento de app aberta

| Campo | Plano |
|-------|--------|
| API | `waitForAppForeground(serial, pkg, { timeoutMs, activity?, onEvent })` |
| SC | SC-05 poll foreground (`dumpsys window` / `pidof` + package ativo) |
| Passos | 1) Poll package em foreground. 2) Opcional: activity atual. 3) Emitir `app_foreground`. |
| Gap | Só `isPackageForeground` (pidof); precisa critério de foreground real + wait com timeout. |
| Aceite | [`4.bdds.md`](4.bdds.md#us-03--evento-de-app-aberta) |

### US-04 — Evento de tela estável

| Campo | Plano |
|-------|--------|
| API | `waitForUiStable(serial, { timeoutMs, stableMs, onEvent })` |
| SC | SC-06 comparar dumps/hashes consecutivos sem mudança por `stableMs` |
| Passos | Dump periódico → hash XML → N samples iguais → `ui_stable`. |
| Gap | `waitForUiReady` espera dump/`contains`; não mede estabilidade temporal. |
| Aceite | [`4.bdds.md`](4.bdds.md#us-04--evento-de-tela-estável) |

### US-05 — Evento de mudança de dump

| Campo | Plano |
|-------|--------|
| API | `waitForDumpChange(serial, { previousXml?, timeoutMs, onEvent }) → { xml }` |
| SC | SC-07 poll até hash ≠ anterior; devolver dump atual |
| Passos | Guardar dump/hash base; poll `dumpUiXml`; quando muda, emitir `dump_changed`. |
| Gap | Não existe; reutilizar `dumpUiXml` de extract. |
| Aceite | [`4.bdds.md`](4.bdds.md#us-05--evento-de-mudança-de-dump) |
