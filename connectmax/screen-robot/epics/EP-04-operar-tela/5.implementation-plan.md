#### Passo a passo

| # | Chamada | Por quê | Entradas | Execução | Saídas |
|---|---------|---------|----------|----------|--------|
| 1 | Dev → Operate: `launch(serial, pkg, activity?)` | Abrir app no agent | `serial`, `pkg`, `activity?` | Recebe pkg/activity e orquestra launch + confirmação de foreground | Promise ok |
| 2 | Operate → AdbClient: `am start` / `monkey` | Disparar activity/package | `pkg`/`activity` | Monta e envia `am start` (ou monkey) com o package/activity alvo | comando enviado |
| 3 | AdbClient → Device: launch | App sobe no Android | intent | O Activity Manager inicia a activity no Android | app iniciando |
| 4 | Operate → Events: `waitForAppForeground(pkg)` | Confirmar foreground real | `pkg`, timeout | Chama waitForAppForeground até o package estar na frente ou timeout | foreground |
| 5 | Events → Operate: `foreground` | Condição de pronto | — | Confirma foreground e libera o Operate a concluir | ok interno |
| 6 | Operate → Dev: `ok` | Launch concluído | — | Resolve a Promise indicando que o app está aberto | void/ok |

#### Contratos

| | Contrato |
|--|----------|
| **API** | `launch(serial, pkg, activity?) → Promise<void>` |
| **Entrada** | `serial`; `pkg`; `activity?` |
| **Pré** | Device Booted; package instalado |
| **Saída** | App em foreground (via `waitForAppForeground`) |
| **Erro** | `OP_LAUNCH_FAILED` · `EVENT_APP_TIMEOUT` |
