#### Agentes

| Agente | Responsabilidade |
|--------|------------------|
| Caller | Pede árvore fase 1 (textos) e depois a árvore completa tipada |
| Extractor | Faz dump, parseia textos e compõe icons/lists/images na fase 2 |
| Device | Fornece o dump uiautomator (e evidência visual se necessário) |

#### Passo a passo

| # | Chamada | Por quê | Entradas | Execução | Saídas |
|---|---------|---------|----------|----------|--------|
| 1 | Dev → Extract: `extractTextTree(serial)` | Fase 1: textos rápidos | `serial` | Inicia a fase 1: dump da UI e montagem da árvore só com textos | Promise tree fase 1 |
| 2 | Extract → Device: `uiautomator dump` | Obter XML da UI | — | Executa uiautomator dump no device e faz pull do XML | xml |
| 3 | Device → Extract: `xml` | Hierarquia bruta | — | Entrega o XML bruto ao parser | string XML |
| 4 | Extract → Extract: parse → árvore textos | Normalizar nodes `kind=text` | xml | Percorre o XML, extrai nodes de texto e monta a árvore `kind=text` | tree parcial |
| 5 | Extract → Dev: tree fase 1 | Entrega rápida | — | Devolve `{ tree, xml }` da fase 1 ao caller | `{ tree, xml }` |
| 6 | Dev → Extract: `extractFullTree(serial\|tree)` | Fase 2: árvore tipada completa | Inicia a fase 2: enriquece a árvore com ícones, listas e imagens | Orquestra extractors | Promise tree full |
| 7 | Extract → Extract: icons + lists + images | Preencher kinds não-texto | tree/xml/frame | Chama os extractors de icons, lists e images sobre dump/frame/tree | subárvores |
| 8 | Extract → Extract: compor hierarquia | Árvore única coerente | subárvores | Mescla as subárvores em uma hierarquia única tipada | tree completa |
| 9 | Extract → Dev: tree completa | DOM usável pelo robot | — | Devolve `{ tree }` completa ao caller | `{ tree }` |

#### Contratos

| | Contrato |
|--|----------|
| **API** | `extractTextTree(serial) → { tree, xml }` · `extractFullTree(serial\|tree) → { tree }` |
| **Entrada** | `serial` **ou** árvore fase 1 + dump/frame |
| **Pré** | Device Booted; UI dumpável |
| **Saída** | Fase 1: árvore `kind=text`; Fase 2: árvore completa tipada |
| **Erro** | `EXTRACT_DUMP_FAILED` · `EXTRACT_EMPTY_TREE` |

## Modelos

### UiNode / ComponentTree

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | `string` | id estável na árvore |
| `kind` | `text\|icon\|list\|image\|node\|…` | Tipo |
| `label` / `text` | `string` | Conteúdo |
| `bounds` / `center` | `number[]` | Geometria |
| `children` | `UiNode[]` | Hierarquia |

### Erros

| Código | Quando |
|--------|--------|
| `EXTRACT_DUMP_FAILED` | Dump indisponível |
| `EXTRACT_EMPTY_TREE` | Sem nodes úteis |
