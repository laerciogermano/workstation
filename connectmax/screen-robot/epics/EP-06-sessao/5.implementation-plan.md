#### Passo a passo

| # | Chamada | Por quê | Entradas | Execução | Saídas |
|---|---------|---------|----------|----------|--------|
| 1 | Dev → Session: `saveSession(path, state)` | Persistir progresso do robot | `path`, `SessionState` | Recebe path + state e prepara a serialização persistente | Promise `absPath` |
| 2 | Session → Session: merge `savedAt` | Carimbar momento do save | state atual | Injeta `savedAt` (ISO) no state antes de gravar | state enriquecido |
| 3 | Session → FS: `mkdir` + write JSON | Gravar no disco | `path`, JSON | Cria diretórios intermediários e escreve o JSON no path | arquivo escrito |
| 4 | FS → Session: `ok` | Persistência ok | — | Confirma que a escrita no disco concluiu sem erro | sucesso |
| 5 | Session → Dev: `absPath` | Path canônico | path resolvido | Resolve com o caminho absoluto do arquivo salvo | string absoluta |

#### Contratos

| | Contrato |
|--|----------|
| **API** | `saveSession(path, state: SessionState) → string` |
| **Entrada** | `path`; estado em memória (`serial`, `apps?`, `step?`, `paths?`) |
| **Pré** | Path gravável |
| **Saída** | Path absoluto do JSON; inclui `savedAt` |
| **Erro** | `SESSION_WRITE_FAILED` |

#### Passo a passo

| # | Chamada | Por quê | Entradas | Execução | Saídas |
|---|---------|---------|----------|----------|--------|
| 1 | Dev → Session: `removeSession(path)` | Limpar sessão persistida | `path` | Recebe o path e inicia remoção idempotente do arquivo de sessão | Promise `{ removed }` |
| 2 | Session → FS: `unlink` se existe | Apagar arquivo | `path` | Apaga o arquivo se existir; se já não existir, trata como removed=false | removed true/false |
| 3 | Session → Dev: limpar contexto runtime | Memória alinhada ao disco | handles/estado em RAM | Zera handles/estado em memória associados à sessão removida | contexto limpo |
| 4 | Session → Dev: `{ removed: boolean }` | Resultado idempotente | — | Resolve com `{ removed: true|false }` conforme o unlink | flag removed |

#### Contratos

| | Contrato |
|--|----------|
| **API** | `removeSession(path) → { removed: boolean }` |
| **Entrada** | `path` da sessão |
| **Pré** | — (idempotente) |
| **Saída** | Arquivo inexistente; contexto runtime limpo |
| **Erro** | Falha de FS (raro); preferir idempotente |

#### Passo a passo

| # | Chamada | Por quê | Entradas | Execução | Saídas |
|---|---------|---------|----------|----------|--------|
| 1 | Dev → Session: `restoreSession(path)` | Retomar de um save | `path` | Recebe o path e inicia leitura + validação do save | Promise `SessionState` |
| 2 | Session → FS: read JSON | Carregar bytes | `path` | Lê o conteúdo JSON do disco | string/objeto bruto |
| 3 | Session → Dev: erro | Arquivo ausente/inválido | código | Se o arquivo faltar ou for inválido, rejeita com SESSION_NOT_FOUND/INVALID | `SESSION_NOT_FOUND`\\|`INVALID` |
| 4 | Session → Session: validar schema | Garantir campos usáveis | JSON parseado | Valida campos obrigatórios do schema e rejeita se incompleto | state válido |
| 5 | Session → Dev: `state` | Sessão restaurada | — | Resolve com o SessionState pronto para o robot retomar | `SessionState` |

#### Contratos

| | Contrato |
|--|----------|
| **API** | `restoreSession(path) → SessionState` · `loadSession(path) → SessionState \| null` |
| **Entrada** | `path` existente |
| **Pré** | Arquivo JSON válido |
| **Saída** | Estado restaurado (schema validado) |
| **Erro** | `SESSION_NOT_FOUND` · `SESSION_INVALID` |

## Modelos

### SessionState

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `serial` / `device` | `string` | Device |
| `apps` | `object?` | Versões/pacotes |
| `step` | `string?` | Etapa do fluxo |
| `paths` | `object?` | screenshot/session |
| `savedAt` | `ISO-8601` | Persistência |

### Erros

| Código | US |
|--------|-----|
| `SESSION_WRITE_FAILED` | US-17 |
| `SESSION_NOT_FOUND` | US-19 |
| `SESSION_INVALID` | US-19 |

Cenário: US-17 Sessão é gravada em disco

Cenário: US-18 Sessão é removida

Cenário: US-19 Sessão é recuperada

  Quando a leitura reaplica o contexto
