# UX/UI 2026: calm interfaces (síntese)

Fonte: https://elements.envato.com/learn/ux-ui-design-trends  
Baixado: 2026-11-08

## TL;DR

Espetáculo visual cede a **clareza cognitiva**. Premiação: julgamento e restraint, não novelty.

## Tendências

1. **AI-native transparente** — usuário vê/porquê e pode override
2. **Calm UI** — menos clutter, defaults claros, menos decisões por sessão
3. **Motion que explica** — progresso, confirmação, orientação; não teatro
4. **A11y como infraestrutura** — contraste, teclado, reduced motion, linguagem clara
5. **Multimodal** — touch / teclado / voz / contexto
6. **Tokens** — cor, type, space, motion, radius mudáveis sem reescrever o produto

## Erros comuns

- Shipar layout AI sem teste de usabilidade
- Novelty > clareza
- A11y depois do launch
- Adotar tendência sem validar no próprio público
