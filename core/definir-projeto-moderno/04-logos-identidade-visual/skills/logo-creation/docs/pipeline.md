# The pipeline in depth

Seven phases, each with a gate — a question that must be answerable before
moving on. The gates are the point. Without them the process collapses into
"draw something and rationalise it afterwards."

Full instructions live in [`../SKILL.md`](../SKILL.md); the depth behind each
phase lives in [`../references/`](../references/). This page explains the shape
of the thing and why it is ordered the way it is.

## 1 — Strategy

**Gate: one sentence, one emotion, one audience.**

The brief forces exactly *one* primary emotion. This is the most-resisted rule
in the pipeline and the most important. Three emotions produce a mark that
evokes none of them, because every design decision that would sharpen one blunts
another.

If the client cannot or will not answer, the assumptions get written down *as
assumptions* and the work continues. What is not allowed is quietly inventing
answers and presenting them as fact.

## 2 — Differentiation

**Gate: name three things this logo will deliberately not do.**

This is where the "generic AI logo" problem actually gets solved. Not by
prompting harder — by researching what the category already looks like and
writing an explicit avoid list.

The test that catches genericness: *could this mark be swapped onto a
competitor's building with no one noticing?* If yes, it is a category
illustration, not a brand.

## 3 — Direction

**Gate: the client picks one of three routes.**

Three routes, each a different *strategic idea*: representational, abstract,
typographic. Three variations on one idea is one route, not three.

Each route is sketched as a rough SVG so the choice is made by eye. Descriptions
flatter bad ideas; rendering exposes them. Concepts that read beautifully in
prose regularly turn out to be a lowercase "b", a power button, or a leaf.

## 4 — Construction

**Gate: cover the wordmark — is the symbol still recognisable?**

The mark is built on a grid with one organising geometry, optical corrections
applied by eye, and counter-space wide enough to survive rasterisation. Symbol
and wordmark are built as separate reusable components, never as one monolithic
path.

If the symbol is anonymous under that cover, the failure is in the concept and
the work returns to Phase 3 — not to more polishing.

## 5 — System

**Gate: every file in the deliverables matrix exists.**

A logo is not a file, it is a system: icon, wordmark, horizontal and stacked
lock-ups, each in full colour, pure black, pure white, and dark mode. A system
with gaps is a mark that will be improvised badly by whoever needs the missing
case at 5pm on a Friday.

## 6 — Validation

**Gate: zero validator errors, four tests passed with reasoning recorded.**

Two layers: an automated structural check, and four perceptual tests that need
human eyes. Both are mandatory, and they catch different things — the validator
will happily pass a wordmark whose letterforms are visibly broken.

Scoring is honest by design. The report format requires a stated reason for
every pass, because "PASS" with no reasoning is how failures ship.

## 7 — Presentation

**Gate: would this survive a client review?**

The mark is presented in use — business card, app icon, signage, avatar — not
floating on white. The strategy is presented *before* the shape, so the mark is
judged against the brief rather than against taste.

Three finished identities are never presented at this stage. That choice
belonged to Phase 3. Presenting three finished options at the end pushes the
decision onto taste and produces a committee compromise.

## Critique mode

Auditing an existing mark skips Phases 3–5: infer the strategy the mark
currently communicates, run the validator and the four tests, then report what
it says versus what the brand needs, test-by-test failures, and the smallest set
of changes that fixes them.

A polite critique that lets a 16-pixel failure ship is a bad critique.
