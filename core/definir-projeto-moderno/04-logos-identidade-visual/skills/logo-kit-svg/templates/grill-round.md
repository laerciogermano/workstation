# Grill round (logo / brand context)

Copy this shape per question. Adapt wording; keep number, type, recommended answer, source, then **wait**.

```markdown
**Subject:** <repo or product — one line>
**Cadence:** one-at-a-time | frontier-round
**Tone:** softer | default | harder

### Q<n>. <one decision about mark, copy, kit, or constraints>
- **Type:** fact | decision
- **Recommended:** <choice>. <one-line why>
- **Source:** <README path, theme file, TRADEMARKS.md, or "user stated" | "unknown — looked, not found">

<wait for the user>
```

**Frontier round:** stack Qn–Q(n+k) in one message (still one rec each), then wait once.

Logo-specific nodes to cover before concepts (implicit tree — do not dump the whole list):

- Wordmark split / accent syllable vs repo name on disk
- Tagline vs motto vs terminal-card story (one narrative or three layers?)
- Mark metaphor (tooling, domain object, abstract) and what to avoid from library research
- Animation appetite (subtle CSS only vs static-first)
- Kit tier and whether presentation board is worth the cost
- Trademark posture (study-only library marks vs net-new geometry)
