# LogoLounge 2026 — motivos formais (mapa de saturação)

Fonte: [2026 Logo Trend Report](https://www.logolounge.com/trend/2026-logo-trend-report) — Bill Gardner; base >30k logos.

**Uso:** saber o que está “gasto” no mercado. Não é menu para copiar.

| Motivo | Leitura rápida | Risco |
|--------|----------------|-------|
| **V Balls** | Círculos + “braços” em V = pessoas/celebração; órbita | Clichê comunidade |
| **Slip Knots** | Letra líder com cauda em nó; vira ícone solo | Monograma desalinhado do wordmark |
| **Slant Break** | 1–2 itálicos no meio de romanos | Fácil de fazer genérico |
| **Piano** | Linhas paralelas / speed lines (eco LA84) | Retro-default “rápido” |
| **Faders** | Aperture + path monoline + fade gradient = “AI thinking” | Orb/aperture AI-slop |
| **Crack** | Ink traps exagerados / anatomia tipográfica | Provocação > legibilidade |
| **Breezy** | Distorsão de pressão / midsection warping | Gimmick sem brief |
| **Roll Over** | Fita/papel em roll (volume, tensão) | Gradiente ribbon genérico |
| **Slash Bar** | Paralelogramos / corte diagonal = momentum | Modular demais, perde alma |
| **Echo Arcs** | Arcos concêntricos / radiantes | Pattern wallpaper |
| **Colorforms** | Kit geométrico Bauhaus/playful; negativo deliberado | Sem ideia = Lego brand |
| **Quad Quivers** | Quadrantes / quatro unidades em vibração | Tech grid clichê |
| **Open Axis / Phasers / Tri-Link** | Eixos abertos, phaser beams, tri-links | SaaS “conexão” default |

## Meta-sinais (além dos nomes)

- Fundos atmosféricos ativos (blur, ripple, droplet)  
- Designers como arquitetos de **toolkits** (cliente diala intensidade)  
- Verde dominante; combinações “ilegais” amarelo/roxo  
- Counters preenchidos com formas inesperadas  

## Filtro para este lab

Se o conceito proposto parecer um dos motivos acima **sem** relação específica ao brief → regenerar.  
Se usar o motivo com intenção explícita (história da marca) → documentar o porquê no checkpoint.
