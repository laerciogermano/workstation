# Prompts IA e caminho até SVG (2026)

## Veredito

- Prompt bom = subject + style + palette + mood + **constraints técnicos**.
- Sem constraints → ilustração; com constraints → “parece logo”.
- Geração de imagem = **conceito**. Master = SVG editável (Recraft ou redesenho manual / skill).
- Preferir `no text` no mark; wordmark tipográfico separado.
- Keywords que ajudam vetorização: flat, vector style, solid colors, clean lines, simple shapes, white/transparent bg.
- Evitar: photorealistic, textured, watercolor, gradient mesh, 3D rendering.

## Ferramentas (contexto 2026 — nomes mudam)

- Exploração estilizada: Midjourney
- Instruções literais: GPT-Image / DALL·E lineage
- Tipo legível em imagem: Ideogram (ainda redesenhar depois)
- Vetor nativo: Recraft (ainda auditar)

## Vetorização

Antes de investir tempo: legível ~2 cm, ≤4–5 áreas de cor, geometria descrevível.  
Preferir Pen tool / construção geométrica a Image Trace cego. Soft edges e micro-gradientes de raster confundem auto-trace.

Fontes: ManyPixels, SVG Genie, Evoke Studio, VectoSolve.
