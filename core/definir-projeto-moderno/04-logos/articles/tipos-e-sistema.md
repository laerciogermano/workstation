# Tipos de logo e sistema de identidade

## Sete tipos (taxonomia prática)

1. **Wordmark** — só o nome tipográfico (Google, FedEx)
2. **Lettermark / monogram** — iniciais (IBM, CNN)
3. **Pictorial** — objeto reconhecível (Apple, Target)
4. **Abstract** — forma não literal (Nike swoosh, Airbnb Belo)
5. **Mascot** — personagem
6. **Combination** — texto + símbolo (default para marcas novas)
7. **Emblem** — texto dentro de selo/escudo (BMW, Starbucks)

Fontes: logodesignxperts / AND Academy / Figma.

## Sistema (não um arquivo)

Marcas sérias mantêm:

- **Primary** — lockup completo
- **Secondary** — icon-only / wordmark-only
- **Responsive** — simplificação para favicon / bordado
- **Mono / reversed** — 1 cor e fundo escuro
- Regras: clear space, mínimo, fundos permitidos, misuse

Smithsonian e guias universitários reforçam: secondary marks **não** substituem o primary em documentos oficiais.

Para produto de software neste lab: no mínimo icon + lockup horizontal + mono + favicon set + `BRAND.md`.
