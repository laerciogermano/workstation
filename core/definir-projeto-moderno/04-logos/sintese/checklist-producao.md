# Checklist de produção — logo

Usar antes de aprovar / entregar. Bases: skills `logo-design`, `logo-creation`, Adobe 7-step, SVG Genie.

## Ideia

- [ ] Brief escrito (nome, o quê, quem, adjetivos, restrições)
- [ ] Clichês da categoria listados e evitados (ou reinventados de propósito)
- [ ] Uma ideia / metáfora principal, explicável em uma frase
- [ ] Tipo de marca escolhido conscientemente (≥2 rotas exploradas)

## Forma

- [ ] Silhueta legível (squint / blur)
- [ ] Lê em ~2 s para estranho (processing fluency)
- [ ] Funciona em 16 px e 32 px
- [ ] Funciona em preto puro e branco puro (e fundo escuro)
- [ ] Sem dependência de gradiente / glow / textura / 3D
- [ ] Espaço negativo intencional (se houver “truque”, sobrevive em mono)

## Arquivo

- [ ] Master SVG com `viewBox`
- [ ] Paths/shapes editáveis — **sem** raster embutido / `<image>`
- [ ] ≤3 cores de marca (ou 1 + neutros)
- [ ] Hex da marca documentados
- [ ] Variantes: color, mono black, mono white/reversed, icon-only
- [ ] Lockups horizontal/stacked se combination
- [ ] Clear space + tamanho mínimo documentados

## Contexto

- [ ] Favicon / app icon
- [ ] Header de site (claro e escuro)
- [ ] Shelf test vs. 3–5 concorrentes (não some na prateleira)
- [ ] Sem conflito óbvio de trademark (checagem humana)

## Identidade (se pedida)

- [ ] Tipografia primaria/secundária com licença ok
- [ ] Paleta com contraste WCAG onde for UI
- [ ] `BRAND.md` / guidelines curtas + usos proibidos
