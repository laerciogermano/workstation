# Kinetic + responsive — níveis honestos

Fonte: [Malbar Design — Kinetic Logo Design](https://malbardesign.com/kinetic-logo-design/) (Jun/2026).

## Definição

Kinetic logo = mark desenhado como **sistema de estados**. O estático continua existindo (print, carimbo); é **um** estado entre reveal, idle loop, hover e variante pequena.

Por que 2026: canais motion-nativos; tooling barato (Lottie/Rive/Jitter); logos estáticos AI-competent → motion vira diferenciação.

## Três níveis

| Nível | Produto | Quando |
|-------|---------|--------|
| **1 Micro-motion** | Reveal + loop; geometria fixa | Site/vídeo/app launch — default |
| **2 Responsive** | Wordmark / monogram / glyph 16px mesma DNA | Todo brand digital desde smartphone |
| **3 Living** | Generativo, data/sound/input reactive | Broadcast, festival, tech com engenharia |

Sweet spot lab: **1 + 2**.

## Quando **não** fazer

- Marca vive em print/embalagem/frota  
- Mark estático ainda fraco (animar não conserta)  
- Time não mantém exports por canal  

Coca-Cola script estático sobreviveu a décadas de “static is dead”. Marcas que morrem são as **inconsistentes**, não as quietas.

## Entregáveis de motion

Contratar/produzir formatos explícitos:

- Lottie/JSON ou Rive (web/app)  
- MP4/WebM (vídeo)  
- GIF fallback  
- SVG/EPS/PDF masters estáticos **sempre**

Nunca entregar só MP4 flatten.
