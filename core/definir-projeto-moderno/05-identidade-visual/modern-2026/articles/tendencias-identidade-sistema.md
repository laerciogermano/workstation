# Identidade como sistema 2026 — síntese

Fontes: [Threerooms](https://www.threerooms.com/blog/8-design-trends-shaping-brand-identity-in-2026), [MarqOps Brand Guidelines Template 2026](https://www.marqops.com/blog/brand-guidelines-template).

## 8 shifts (Threerooms)

1. **Motion-first** — easing/duração/logo animado/UI cinética são assets de marca  
2. **Hand-crafted imperfection** — grain, linha irregular, anti-polish AI  
3. **Expressive typography** — tipo como herói da personalidade  
4. **Humanised hybrid intelligence** — IA no fluxo; empatia/voz humana no resultado  
5. **Inclusive / accessible** — AA, legibilidade, não “depois”  
6. **Soft-glow gradients** — atmosféricos, não neon SaaS  
7. **Nostalgic layering** — mashup décadas + forma moderna  
8. **Sensory** — sonic logo, haptics, XR

## Guidelines 2026 = OS para humanos + IA (MarqOps)

12 seções mínimas:

1. Brand story / mission  
2. Logo system  
3. Color (+ dark + WCAG pairs)  
4. Typography (+ type scale)  
5. Voice & tone (sliders + exemplos)  
6. Imagery / photography  
7. Iconography / illustration  
8. **Motion & animation** (novo padrão)  
9. Accessibility  
10. Social / channel adaptations  
11. **AI content rules** (novo padrão)  
12. Do / don’t + one-pager summary  

Sem seções 8 e 11, o kit está **desatualizado** para 2026.

## AI content rules (mínimo)

- O que IA pode gerar sem review vs. o que exige humano  
- Prompts / estilos proibidos (slop list)  
- Disclosure quando aplicável  
- Checkpoint visual antes de ship  
- Fonte de verdade: este `BRAND.md` / tokens — não “lembra do moodboard”
