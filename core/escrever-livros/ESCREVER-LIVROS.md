# Escrever livros — veredito

**Data:** 2026-11-09  
**Uso:** referência operacional para IA e autor. Detalhe e fontes em [`SOURCES.md`](SOURCES.md).

## O que é um livro aqui

Unidade longa com **promessa ao leitor**, **tese/arco** e **progressão** (capítulo a capítulo). Não é coleção de posts colados.

Para *Eternos Mutáveis* (e ensaios filosóficos semelhantes): o leitor é o protagonista da alfabetização; a obra ensina um mapa do real; cada capítulo muda o que o leitor **vê** ou **pode dizer**.

## Antes de prosa

| Artefato | Conteúdo mínimo |
|---|---|
| Manifesto / visão | O quê, por quê, para quem, fronteira do escopo |
| Público | 1–3 personas com dor + entrega (não “todo mundo”) |
| Tese do livro | 1 frase |
| TOC | 5–15 capítulos; **tese de 1–2 frases cada**; ler só as teses = argumento |
| Voz | Registro, o que evitar, termos canônicos |
| Outline do capítulo | gancho → tese → pontos/evidência → exemplos → ação/ponte |

## Público

- Imaginar **uma pessoa** (idade, estágio, crença, dor noturna), não demografia vaga.
- Promessa: `[quem] lê sobre [quê] porque [por quê / transformação]`.
- “Todos” não é público. Secundário (ex.: acadêmico) só se o primário estiver claro.
- Cada capítulo: o que o leitor **precisa saber agora** para o próximo passo — não o que o autor quer descarregar.

## Estrutura nonfiction / ensaio

1. **Capítulo = uma ideia coesa**, explorada por completo.
2. Teste do TOC: teses em sequência formam argumento; “e” na tese → talvez 2 capítulos; teses iguais → fundir.
3. Esqueleto de capítulo (Scribe / Jane Friedman):
   - gancho (cena, pergunta, fato)
   - tese explícita
   - ideias + argumentação + provas + histórias
   - takeaway / ponte
4. Filosofia (UCL / Caltech / Melbourne): tese cedo; roadmap; cada parágrafo serve à resposta; objeções e réplicas; clareza > ornamento; signposting.

## Sessões / cenas (também no ensaio)

- **Cena/seção** = bloco onde algo **muda** (conhecimento, tensão, decisão do leitor).
- **Capítulo** = container de ritmo de leitura (onde pausar / virar página), não a unidade lógica.
- Em ficção: Goal → Conflict → Setback; Sequel: Reaction → Dilemma → Decision.
- Em ensaio: pergunta → tensão → insight → custo/consequência → ponte.

## Como escrever com IA (sem virar pasta genérica)

1. Não pedir o livro inteiro de uma vez.
2. Loop: planejar capítulo → contexto mínimo (canônico) → outline de seções → **uma** seção → auditar → atualizar bíblia/outline.
3. Separar passes: lógica → continuidade → voz → copy.
4. System prompt em blocos: papel, lei do projeto, tarefa, restrições, formato, o que **não** revelar / inventar.
5. Skills canônicas neste pacote: `narrative-nonfiction`, `bookwright`, `book-editor`, `avoid-ai-writing`, `humanizer`.

## Revisão (grande → pequeno)

1. Estrutura / argumento / ordem
2. Capítulos e seções (cada uma vira?)
3. Parágrafo e ritmo
4. Frase / terminologia
5. Copy / prova

Polir frase de seção que será cortada = desperdício.

## Anti-padrões

- Capítulo sem tese
- Público “geral”
- Misturar revisão estrutural com polish
- Dump de pesquisa sem “e daí?” para o leitor
- Retórica / pergunta retórica no lugar de argumento
- Tom de IA: lede meta, “neste capítulo vamos…”, listas vazias de takeaway, voz corporativa
