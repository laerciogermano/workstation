## Ordem de uso (ensaio / Eternos Mutáveis)

1. Manifesto + público + tese (1 frase)
2. TOC com tese por capítulo (ler só as teses = argumento)
3. Outline de capítulo: gancho → tese → pontos → exemplos → ponte
4. Rascunho de **uma** seção/capítulo por vez
5. Revisão grande→pequeno: argumento → clareza → linha → copy
