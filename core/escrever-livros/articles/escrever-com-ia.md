# Escrever com IA

Fontes: ZenStory, Ficlora, StoryForge, AIWriteBook, skills bookwright / narrative-nonfiction.

## Loop

```
plano do capítulo → contexto mínimo → cartões de seção →
1 seção → auditoria → atualizar canônico → próxima
```

Nunca o manuscrito inteiro num prompt.

## Contexto mínimo (não “histórico do chat”)

- manifesto / voz / tese
- tese do capítulo + estado de entrada/saída
- resumo aceito do beat anterior
- entradas da bíblia relevantes
- o que não revelar
- amostra de prosa do autor

## Passes separados

1. Lógica (causa/efeito, escolha, mudança)
2. Continuidade (fatos, cronologia, conhecimento do POV)
3. Voz / ritmo
4. Copy

“Melhore tudo” → prosa polida em cena quebrada.

## System prompt em blocos

Papel · lei · tarefa · escopo · estado · conexão · limite · expressão · invenção.
