# Outline nonfiction

Fontes: Scribe, ScribeGuide, Jane Friedman, MW Editing, Reedsy.

## Livro

1. Brainstorm de capítulos (ideia coesa cada um)
2. TOC + **tese de 1–2 frases** por capítulo
3. Ler só as teses: argumento deve fechar
4. 5–15 capítulos é faixa típica

## Capítulo (template)

| Parte | Conteúdo |
|---|---|
| Título provisório | rótulo claro |
| Gancho | história, fato, pergunta |
| Tese | o ponto único |
| Pontos de apoio | 3–5, em ordem lógica |
| Histórias / evidência | casos, dados, citações |
| Ação / takeaway | o que o leitor faz / leva |
| Abertas | o que ainda falta checar |

## Cinco ingredientes (Friedman)

Ideias/frameworks · histórias · argumentação · provas · conselho/aplicação.

Arranjo típico: caso → ideia → framework → por que vale → o que fazer.

## Estruturas

- **Passo a passo** — how-to
- **Ensaio / argumento** — tese central, capítulos como movimentos
- **Lista** — tópicos irmãos sob a mesma promessa
