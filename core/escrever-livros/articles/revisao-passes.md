# Revisão em passes

Fontes: revision skill (jwynia), book-editor, Zach Simms, synthesis-writing-craft.

## Ordem

1. **Estrutural** — argumento, arco, ordem, buracos
2. **Seção/cena** — cada bloco vira? pode fundir/cortar?
3. **Personagem / voz / tese** — consistência
4. **Parágrafo / diálogo**
5. **Linha** — clareza, ritmo, precisão
6. **Copy / prova**

## Princípios

- Grande → pequeno
- Nomear o problema que cada edição resolve
- Preservar mecanismo causal e detalhe decisivo
- Cortar o que não paga aluguel
- Confiar no leitor
- Separar gosto de defeito (com evidência)

## Editor

Assess → staged passes → propor (não impor) mudanças substantivas → explicar o *porquê*.
