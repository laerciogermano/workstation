# Checklist — livro pronto para avançar de fase

## Fundação

- [ ] Promessa em 1 frase
- [ ] Tese do livro em 1 frase
- [ ] 1–3 personas com dor + entrega
- [ ] Fronteiras (o que não é)
- [ ] Voz / termos canônicos documentados

## Estrutura

- [ ] TOC 5–15 (ou justificado fora)
- [ ] Tese por capítulo; sequência = argumento
- [ ] Sem capítulos sem tese / com “e” forçado
- [ ] Outline do próximo capítulo com gancho + pontos + ponte

## Draft

- [ ] Uma unidade por vez (seção/capítulo)
- [ ] Canônico atualizado após aceite
- [ ] Fatos novos listados
- [ ] Sem revelar o que o plano reserva

## Revisão

- [ ] Passe estrutural feito antes de polish
- [ ] Cada seção muda algo para o leitor
- [ ] Anti-slop (lede meta, listas vazias, voz corporativa)
- [ ] Objeções relevantes tratadas (ensaio)

## Gate Eternos Mutáveis

- [ ] Alinha com visão/tese do README do projeto
- [ ] Persona (buscador / religioso inquieto / cético) atendida no capítulo
- [ ] Não troca alfabetização espiritual por jargão opaco
