# Documento de stories

Artefato **1** do [discovery](README.md). Lista das **estórias (US)** com título e descrição do *como funciona* — sem Gherkin.

**Visão do produto** (problema, para quem, objetivo, fora de escopo) fica no `README.md` do projeto.

## Regras

1. Vem **antes** de epics, cenários, BDDs, protótipo e roadmap.
2. Cada US: título + descrição curta de como funciona.
3. Agrupamento em épicos fica em [`2.epics.md`](2.epics.md).
4. Detalhe operacional (entradas/execução/saídas + SC) vai para [`3.scenarios.md`](3.scenarios.md).

## Formato (mínimo)

```markdown
# Stories — <Produto>

## Histórias

| ID | Estória | Como funciona |
|----|---------|---------------|
| US-… | … | … |
```
