# Protótipo

Artefato **5** do [discovery](README.md). Validação visual/interativa do *quê* já fechado em stories, scenarios, BDDs e epics.

**Antes:** [`4.epics.md`](4.epics.md). **Depois:** [`6.roadmap.md`](6.roadmap.md).

## Regras

1. Só depois de stories → scenarios → BDDs → epics.
2. O arquivo concreto fica no projeto (`prototype.html`, Figma, etc.); este doc define o papel no discovery.
3. Serve para validar com stakeholders o comportamento especificado — não substitui BDD nem implementação.

## Saída esperada no projeto

- Protótipo navegável ou artefato visual linkado a partir da pasta `docs/` do produto.
- Cobertura alinhada às US/SC e aos BDDs já escritos.
