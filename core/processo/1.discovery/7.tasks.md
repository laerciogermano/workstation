# Documento de tasks

Artefato **7** do [discovery](README.md). Gantt **TSK** (inclui SC) + inventário de esforço.

**Antes:** [`6.roadmap.md`](6.roadmap.md). **Depois:** [refinamento técnico](../2.refinamento-tecnico/README.md) (por estória).

## Regras

1. Só depois do roadmap.
2. No Gantt: todos os nós com ID **TSK-**; inclui nível SC (e pais EP/US conforme a árvore).
3. **IDs duplos na barra:** cada barra mostra **TSK-** **e** o ID de origem (**EP-**, **US-** ou **SC-**), ex.: `TSK-006 US-02 Evento de boot`, `TSK-002 SC-01 Subir e conectar`, `TSK-001 EP-01 Provisionar agente`.
4. **Pai com uma filha:** no Gantt/tabela, mostrar **só o pai** (não duplicar a SC única).
5. Minutos IA reais nas barras (sufixo `m`) e no inventário/tabela.
6. O arquivo concreto fica no projeto (`tasks.md` / `7.tasks.md`); este doc define o papel no discovery.

## Saída esperada no projeto

- Gantt TSK com IDs TSK + EP/US/SC em cada barra.
- Inventário alinhado a scenarios / épicos.
