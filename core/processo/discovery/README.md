# Discovery

Entender o problema antes de construir.

## Foco

- Problema e contexto
- Usuários e stakeholders
- Valor esperado e métricas de sucesso
- Escopo inicial (in / out)
- Premissas e restrições

## Saídas típicas

- Visão / brief
- Hipóteses a validar
- Escopo preliminar
- Próximo passo: refinamento técnico
