# Documento de functionalities

Artefato **2** do [discovery](README.md). Capacidades observáveis do produto — base para épicos e estórias, **sem** Gherkin nem layout.

**Antes:** [`vision.md`](vision.md). **Depois:** [`scenarios.md`](scenarios.md).

## Regras

1. Só depois da vision.
2. Cada item descreve uma **capacidade observável** (o que o produto faz).
3. Uma funcionalidade pode originar uma ou mais estórias em [`scenarios.md`](scenarios.md).
4. Não antecipar critérios de aceite (BDD), protótipo nem implementação.

## Formato (mínimo)

```markdown
# <Produto> — Funcionalidades

## <Área / tema>

- Capacidade observável …
- Capacidade observável …
```
