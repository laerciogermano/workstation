## Prompt original

```
Crio um novo projeto chamado CRM, é, tanto no centralizador como local, e esse projeto ele vai ser um projeto que... vai conectar WhatsApp, vai conectar Tinder, vai conectar Instagram, vai conectar todas as possíveis aplicações, aplicativos, e ele vai ter um identificador para cada pessoa, e a gente vai conseguir automatizar, mandar mensagem, ter fotos, nome, informações de todos os tipos.
```

## Interpretação

Criar o projeto **CRM** no workstation e no centralizador: hub de pessoas com **ID único**, conexões multi-canal (**WhatsApp, Tinder, Instagram** e extensível), perfil (**foto, nome, informações**) e **automação de mensagens**. Primeiro artefato = documento de visão. Página do projeto (`project.html?p=crm`) com contexto e objetivo. Publicar o centralizador com o card.
