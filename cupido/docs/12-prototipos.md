# Cupido — Protótipos

**Protótipo navegável:** [`prototipos/index.html`](prototipos/index.html). Abra no navegador, sem build.

- **Galeria:** telas por fluxo, celulares com contorno coral/teal.
- **Modo navegável:** clique na tela ou “▶ Navegar”. `data-go` avança. Atalhos: `←/→`, `Backspace`, `H`, `Esc`. Deep-link: `index.html#T-11`.
- **Fidelidade:** **alta** (visual final, conteúdo fictício). Sem app implementado.

> Fonte: [PRD](prd.md) · [identidade](../identidade-visual.md) · [marca](../marca/README.md).

## 1. Princípios

| Princípio | Como aparece |
|---|---|
| Agente no centro | Home = candidatos que o Cupido está operando |
| Anônimo até o fit | Avatar geométrico + “Candidato ···” |
| Coral = conexão | CTA match / encontro |
| Teal = agente | Chips “Agente ativo”, progresso |
| Histórico com consentimento | Tela explícita de importação |
| Um CTA por tela | Coral primário |
