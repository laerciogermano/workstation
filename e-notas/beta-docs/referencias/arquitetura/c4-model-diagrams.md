# Diagrams 
 
## Static structure diagrams 
 

The C4 model is named after the core set of static structure diagrams: (system) context, containers, components, and code.
 

 
 

The different levels of zoom allow you to tell different stories to different audiences. That said, you don’t need to use all 4 levels of diagram ; only those that add value - the system context and container diagrams are sufficient for most software development teams.
 1. System context diagram 2. Container diagram 3. Component diagram 4. Code diagram
