# Linux Foundation Announces the Formation of the Agentic AI Foundation (AAIF)

Source: https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation
Date: 09 December 2025
Downloaded: 2026-11-08

Summary:
- Founding contributions: Anthropic’s MCP, Block’s goose, OpenAI’s AGENTS.md
- AAIF provides a neutral, open foundation for agentic AI
- AGENTS.md: simple universal standard giving AI coding agents project-specific guidance
- Platinum members: AWS, Anthropic, Block, Bloomberg, Cloudflare, Google, Microsoft, OpenAI

AGENTS.md released by OpenAI in August 2025; adopted by more than 60,000 open source projects and frameworks including Amp, Codex, Cursor, Devin, Factory, Gemini CLI, GitHub Copilot, Jules and VS Code.

More: https://aaif.io and https://github.com/aaif
