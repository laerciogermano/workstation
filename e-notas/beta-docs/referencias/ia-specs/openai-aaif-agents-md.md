# OpenAI co-founds Agentic AI Foundation, donates AGENTS.md

Source: https://openai.com/index/agentic-ai-foundation/
Date: December 9, 2025
Downloaded: 2026-11-08

Today, OpenAI is co-founding the Agentic AI Foundation (AAIF) under the Linux Foundation, alongside Anthropic and Block, and with the support of Google, Microsoft, AWS, Bloomberg, and Cloudflare.

As part of this effort, OpenAI is contributing AGENTS.md — a simple, open format for providing agents with project-specific instructions and context — to the foundation.

## Donating AGENTS.md

AGENTS.md began as a practical solution: Codex needed a predictable way to find project-specific instructions — coding conventions, build steps, and testing requirements.

AGENTS.md is a lightweight Markdown file designed to live alongside README.md. It offers a simple, interoperable standard that gives AI coding agents a consistent source of project-specific guidance.

Since its release in August 2025, AGENTS.md has been adopted by more than 60,000 open-source projects and agent frameworks including Amp, Codex, Cursor, Devin, Factory, Gemini CLI, Github Copilot, Jules and VS Code among others.

Contributing AGENTS.md to the AAIF ensures:
- Developers and enterprises have a portable way to provide agents with the context they need
- The format can evolve in the open, with input from many tools and communities
- No single company controls its direction as adoption continues to grow

In addition to AGENTS.md, AAIF co-founders contribute Anthropic’s Model Context Protocol (MCP) and Block’s goose.
