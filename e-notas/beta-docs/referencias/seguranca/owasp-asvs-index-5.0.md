# OWASP ASVS Index (Cheat Sheet Series mapping)

Source: https://cheatsheetseries.owasp.org/IndexASVS.html
Based on ASVS version 5.0.x
Downloaded: 2026-11-08

## Objective
Help ASVS users identify which OWASP Cheat Sheets apply to each ASVS section.

## High-level ASVS 5.0 chapters (V1–V17)
- V1 Encoding and Sanitization
- V2 Validation and Business Logic
- V3 Web Frontend Security
- V4 API and Web Service
- V5 File Handling
- V6 Authentication
- V7 Session Management
- V8 Authorization
- V9 Self-contained Tokens
- V10 OAuth and OIDC
- V11 Cryptography
- V12 Secure Communication
- V13 Configuration (includes Secret Management)
- V14 Data Protection
- V15 Secure Coding and Architecture
- V16 Security Logging and Error Handling
- V17 WebRTC

## Companion usage for agents
- Use ASVS as the verification checklist (what “secure enough” means for the product level)
- Map Node/TS work to cheat sheets: Node.js Security, JS/TS Security, REST, AuthN/AuthZ, Secrets
- Keep a short always-on agent rule set; deep-link ASVS/cheat sheets as on-demand companions (not full dump in AGENTS.md)
