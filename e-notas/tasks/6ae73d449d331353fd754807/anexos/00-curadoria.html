NFC-e → preço, comparado aos 6 requisitos do PRD notinhas.org: comparação, histórico, montagem apartada, vitrine da loja, busca geo (“onde comprar perto”) e API empresas.

1. Requisitos sob análise

Comparação de preços — EAN entre estabelecimentos; menor preço com loja + data.
Histórico de preços — evolução por produto e por mercado.
Montagem apartada — cesta por mercado + divisão 2+ lojas.
Vitrine da loja — tela do estabelecimento com itens como e-commerce (sem checkout).
Busca geo — item → lojas físicas próximas (GPS ou região, ex. centro).
API empresas — integração B2B consulta/alimentação do índice.

3. Leitura por requisito

Comparação de preços

  • Commodity: todos fazem. Baseline = Busca Preço + honestidade Mercado Certo.

Histórico

  • Cheio: Busca Preço, Nota Preço, GoMarket. Gov = só frescor da última venda.

Montagem apartada

  • Só Nota Preço e Mercado Certo com split explícito 2–3 lojas.

Vitrine da loja (e-commerce read-only)

  • GoMarket e Qual o Preço mais perto: produtos/catálogo por mercado.
  • Demais são produto-cêntricos (busca item → lista de lojas), sem “loja como loja”.
  • Gap notinhas: página de estabelecimento estilo grade e-commerce + mapa.

Busca geo — onde comprar fisicamente perto

  • Nota Paraná / MP Brasil / Economiza AL: raio + mapa (padrão gov).
  • Mercado Certo / Qual o Preço / GoMarket: distância nas ofertas / perto de você.
  • Poucos oferecem âncora explícita tipo “estou no centro” (ponto no mapa / região) além do GPS.
  • notinhas: item + (GPS | pin centro/bairro) → lojas ordenadas por distância e/ou preço → vitrine.

API empresas

  • Consumer apps: quase zero. Refs: Quantto (B2B) e Economiza AL (API pública).

4. Ranking (à luz dos 6)

  • 1. Qual o Preço / GoMarket — vitrine + geo; montagem/API mais fracas.
  • 2. Nota Preço / Mercado Certo — montagem apartada referência.
  • 3. Busca Preço — comparação + histórico v1.
  • 4. Nota Paraná / MP Brasil — geo/raio oficial; sem vitrine/split/API B2B.
  • 5. Quantto + Economiza AL — eixo API.
  • 6. PoupApp — lista sem split/vitrine.

5. Implicações notinhas.org

  • Paridade: comparação + histórico + busca geo (já esperada no PR por causa do Nota Paraná).
  • Diferenciais: vitrine e-commerce da loja, montagem apartada, API empresas, âncora “centro/bairro” além do GPS.
  • Não competir com SEFAZ em “ter o dado”; competir em UX de compra física + B2B.
