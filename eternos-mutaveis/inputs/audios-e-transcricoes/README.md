# Áudios e transcrições

**Por quê:** isolar gravações (`.m4a`) e textos derivados da fala, separados dos documentos-fonte.  
**Pai:** [`../README.md`](../README.md).

Cada áudio costuma ter um `.txt` homônimo. Também estão aqui `transcricao.txt` e `transcricao-bullets.md` (abertura já usada no artigo).

Cada transcrição `.txt` tem um resumo em tópicos no arquivo `<nome> bullets.txt` (mesmo nome + ` bullets`). Para reverter, apagar os `* bullets.txt`; as transcrições originais não foram alteradas.

Documentos (briefing, tratados, livros) permanecem em [`../`](../README.md).
