01Flow

Fluxo de execução: dados + funções. Código universal que o canvas desenha.

async function atenderPedido(state) {
  const { pedido } = await receberPedido({ ...state });
  const { itens } = await separarItens({ ...state, pedido });
  return { pedido, itens };
}

02Funções

Unidade de transformação. Filhas, irmãs, sequência, paralelo, entrada e saída.

function calcularTotal({ preco, quantidade }) {
  return { total: preco * quantidade };
}
async function venderProduto(state) {
  async function cobrarCliente(s) {
    return { pagamento: s.cliente };
  }
  const { pagamento } = await cobrarCliente(state);
  return { pagamento };
}
async function pipeline(state) {
  const a = await passoA(state);
  const b = await passoB({ ...state, ...a });
  return b;
}
async function carregarPainel(state) {
  const [user, feed] = await Promise.all([
    buscarUser(state),
    buscarFeed(state),
  ]);
  return { user, feed };
}

03Dados

Unidades transformáveis: input / output. Texto, número, booleano, função, array, objeto.

const nome = "Ana";
const preco = 1999.9;
const ativo = true;
const transformar = (x) => x * 2;
const itens = ["a", "b", "c"];
const cliente = { nome: "Ana", idade: 30 };

04Estados

Dados disponíveis em cada passo. Estado inicial entra; estado final sai.

async function fluxo(state) {
  const s1 = { ...state, pedido: await receber(state) };
  const s2 = { ...s1, total: s1.pedido.preco * s1.pedido.qtd };
  return s2;
}

05Agentes

Fonte da execução: arquivo, pessoa, IA, biblioteca — quem realiza o trabalho.

async function enviarProposta(state, agents) {
  const rascunho = await agents.arquivo.ler(state.cliente);
  const texto = await agents.ia.redigir(rascunho);
  return agents.pessoa.revisar(texto);
}

06Seleção

Condiciona o caminho do fluxo conforme o dado: if/else e switch.

function aplicarDesconto({ preco, vip }) {
  if (vip) {
    return { total: preco * 0.9 };
  } else {
    return { total: preco };
  }
}
function rota({ status }) {
  switch (status) {
    case "novo":
      return { passo: "cobrar" };
    case "pago":
      return { passo: "enviar" };
    default:
      return { passo: "aguardar" };
  }
}

07Repetição

Estruturas repetíveis: for, while, do-while.

function somar({ itens }) {
  let total = 0;
  for (const item of itens) {
    total += item.preco;
  }
  return { total };
}
function esperar({ pronto }) {
  let n = 0;
  while (!pronto && n < 10) {
    n += 1;
  }
  return { tentativas: n };
}
function lerAteOk({ ler }) {
  let pagina;
  do {
    pagina = ler();
  } while (!pagina.ok);
  return pagina;
}

08try / catch

Tratamento de erro: o fluxo continua no ramo catch com o dado error.

async function buscarSeguro(state) {
  try {
    return await buscar(state);
  } catch (error) {
    return { error, fallback: true };
  }
}

09Files (Layers)

Todo dado e toda função têm endereço. Quem se conhece mora na mesma camada.

import { formatPrice } from "./utils.js";

export async function checkout(state) {
  const { total } = await formatPrice(state);
  return { total };
}

10Sólidos × abstratos

Sólido tem endereço físico (valor/produtor). Abstrato ainda não — chega pelo state.

function rotular({ titulo }) {
  const selo = "oficial";
  return { rotulo: titulo + " · " + selo };
}

11Público / privado

Público: export / acesso de fora. Privado: só o módulo/caixa enxerga.

function normalizar(nome) {
  return nome.trim().toLowerCase();
}

export function criarCliente({ nome }) {
  return { nome: normalizar(nome) };
}

12Boas práticas — SOLID

Responsabilidade única: um verbo, uma transformação.

function calcularFrete({ peso, distancia }) {
  return { frete: peso * distancia * 0.12 };
}

function emitirNota({ pedido, frete }) {
  return { nota: { pedido, frete } };
}

13Padrões de projeto

Factory e singleton — como no Flow a criação e a fonte única se isolam do roteiro.

function criarAgente(kind) {
  if (kind === "pessoa") return { ask: (t) => t };
  if (kind === "ia") return { ask: (t) => "ia:" + t };
  return { ask: (t) => "lib:" + t };
}
const Store = (function () {
  let instance;
  return {
    get() {
      if (!instance) instance = { state: {} };
      return instance;
    },
  };
})();

14OOP × Flow

Na OO, dado e comportamento acoplam na classe. No Flow, função e estado separam — a “instância” é o state entre verbos.

class Pedido {
  constructor(itens) {
    this.itens = itens;
  }
  total() {
    return this.itens.reduce((s, i) => s + i.preco, 0);
  }
}
function total({ itens }) {
  return { total: itens.reduce((s, i) => s + i.preco, 0) };
}
