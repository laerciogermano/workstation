## História

Como usuário do Board, quero **mover um card** entre colunas, para atualizar o status do trabalho no kanban.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Arrastar card

Quando o usuário **pressionar e arrastar um card** no Board, o sistema deve **iniciar o gesto de mover**.

### SC-02 — Soltar em outra coluna

Quando o usuário **soltar o card em outra coluna**, o sistema deve **mover o card** para essa coluna.

### SC-03 — Card atualizado no Board

Quando o card **for movido**, o sistema deve **exibi-lo na coluna destino** e **removê-lo da coluna de origem**.
