## História

Como usuário do Board, quero **criar uma raia**, para agrupar colunas por projeto ou prioridade no kanban.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Clicar no + do indicador da raia

Quando o usuário **clicar no +** do indicador da raia, o sistema deve **oferecer a escolha** de criar a nova raia **acima** ou **abaixo**.

### SC-02 — Escolher posição e dar nome

Quando o usuário **escolher acima ou abaixo**, o sistema deve **abrir a opção de dar nome** à nova raia na posição escolhida.

### SC-03 — Confirmar nome com Enter

Quando o usuário **der o nome e pressionar Enter**, o sistema deve **criar a raia** na posição escolhida.

### SC-04 — Raia aparece no Board

Quando a raia **for criada**, o sistema deve **exibi-la no Board** (acima ou abaixo, conforme a escolha), com espaço para colunas e cards.
