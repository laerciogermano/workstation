## História

Como usuário do Board, quero **criar uma raia**, para agrupar colunas por projeto ou prioridade no kanban.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Criar raia no Board

Quando o usuário **acionar criar raia** no Board, o sistema deve **abrir a opção de dar nome** à nova raia.

### SC-02 — Confirmar nome com Enter

Quando o usuário **der o nome e pressionar Enter**, o sistema deve **criar a raia** no Board.

### SC-03 — Raia aparece no Board

Quando a raia **for criada**, o sistema deve **exibi-la no Board**, com espaço para colunas e cards.
