## História

Como usuário do Gantt, quero **mover uma tarefa por drag and drop**, para ajustar a posição temporal da atividade no cronograma.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Arrastar tarefa no Gantt

Quando o usuário **pressionar e arrastar uma tarefa** no Gantt, o sistema deve **iniciar o gesto de mover**.

### SC-02 — Soltar em nova posição

Quando o usuário **soltar a tarefa em outra posição** do cronograma, o sistema deve **mover a tarefa** para essa posição no tempo.

### SC-03 — Tarefa atualizada no Gantt

Quando a tarefa **for movida**, o sistema deve **exibi-la na nova posição** do Gantt.
