## História

Como usuário do Gantt, quero **atribuir a data de saída** de uma tarefa, para definir quando a atividade termina no cronograma.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Selecionar tarefa

Quando o usuário **selecionar uma tarefa** no Gantt, o sistema deve **permitir atribuir a data de saída**.

### SC-02 — Informar data de saída

Quando o usuário **informar a data de saída**, o sistema deve **associar essa data** à tarefa.

### SC-03 — Saída refletida no Gantt

Quando a saída **for atribuída**, o sistema deve **posicionar o fim da tarefa** nessa data no Gantt.
