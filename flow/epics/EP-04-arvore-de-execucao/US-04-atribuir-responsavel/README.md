## História

Como usuário da Árvore de execução, quero **atribuir um responsável** a uma atividade, para saber quem executa o nó.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Clicar no responsável do nó

Quando o usuário **clicar no responsável** (ou ícone de responsável) **na linha da atividade**, o sistema deve **abrir a opção com as opções de responsáveis**.

### SC-02 — Opção Atribuir responsável no menu transversal

Quando o usuário **selecionar uma atividade** e no **menu transversal** **clicar no ícone Atribuir responsável**, o sistema deve **abrir a opção com as opções de responsáveis**.

### SC-03 — Escolher responsável

Quando o usuário **escolher um responsável** na lista, o sistema deve **associar esse responsável** à atividade.

### SC-04 — Responsável visível na árvore

Quando o responsável **for atribuído**, o sistema deve **exibi-lo na linha da atividade** na Árvore de execução.
