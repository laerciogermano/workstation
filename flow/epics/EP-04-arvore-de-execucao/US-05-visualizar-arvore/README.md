## História

Como usuário da Árvore de execução, quero **visualizar a floresta de atividades**, para acompanhar a hierarquia de pais e filhos fora do eixo temporal do Gantt.

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Abrir a Árvore de execução

Quando o usuário **abrir a Árvore de execução**, o sistema deve **exibir as atividades** em hierarquia.

### SC-02 — Floresta com múltiplas raízes

Quando houver **múltiplas atividades raiz**, o sistema deve **exibir todas as raízes** e suas hierarquias.

### SC-03 — Visualizar responsável

Quando as atividades **forem exibidas**, o sistema deve **mostrar o responsável** na **linha de cada atividade**.

### SC-04 — Expandir e recolher

Quando o usuário **expandir ou recolher** um nó, o sistema deve **mostrar ou ocultar** os filhos desse nó.

### SC-05 — Árvore vazia

Quando **não houver atividades**, o sistema deve **exibir a árvore vazia** e **utilizável** (pronta para criar).
