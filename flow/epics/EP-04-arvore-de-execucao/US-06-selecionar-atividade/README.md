## História

Como usuário da Árvore de execução, quero **selecionar uma atividade**, para operar sobre ela (criar filha, mover, remover, atribuir, etc.).

## Print

_(protótipo pendente)_

## Cenários

### SC-01 — Clicar na atividade

Quando o usuário **clicar em uma atividade** na árvore, o sistema deve **selecionar essa atividade**.

### SC-02 — Atividade destacada

Quando a atividade **for selecionada**, o sistema deve **destacá-la visualmente** na árvore.

### SC-03 — Menu de opções transversais

Quando o usuário **selecionar a atividade**, o sistema deve **exibir um menu com as opções transversais** disponíveis para essa atividade.

### SC-04 — Trocar seleção

Quando o usuário **clicar em outra atividade**, o sistema deve **selecionar a nova atividade**, **atualizar o menu de opções transversais** e **deixar de destacar** a anterior.
