## Prompt original

```
Crio um projeto chamado Gamification. Esse projeto vai servir pra criar metas, bônus, acompanhar a performance dos profissionais e bonificar de acordo com suas condutas de se estão fazendo as coisas obrigatórias, diárias e tudo mais.

O objetivo é a gente... bonificar pessoas com boa conduta pra gente elevar Pra gente elevar a qualidade da nossa operação, fazer as coisas que nós somos obrigados a fazer, pra que a gente consiga, por exemplo, prospectar leads, follow-up... campanhas e assim vendermos mais.
```

## Interpretação

Criar o projeto **Gamification** no workstation: sistema de **metas**, **bônus** e **acompanhamento de performance**, bonificando **boa conduta** (obrigatórios, diários etc.) para **elevar a qualidade da operação** — prospecção, follow-up, campanhas — e **vender mais**. Primeiro artefato = documento de visão. Página do projeto (`project.html?p=gamification`) com contexto e objetivo.
