## História

Como **arquiteto de fluxo**, quero que **tarefas com responsável máquina sejam tratadas como linguagem de programação**, para **usar bibliotecas, loops e estados (entradas/saídas) no Gantt**.

## Critérios de aceite

- [ ] Com responsável máquina, a tarefa/Gantt opera como linguagem de programação
- [ ] Posso usar bibliotecas de programação
- [ ] Posso definir laços de repetição / loops
- [ ] Estados são expressos como entradas e saídas (Flow Oriented Programming)
