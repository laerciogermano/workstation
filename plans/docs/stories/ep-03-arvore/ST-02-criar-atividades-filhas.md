## História

Como **planejador**, quero **criar atividades filhas a partir de qualquer atividade**, para **decompor o trabalho sem limite de profundidade**.

## Critérios de aceite

- [ ] Posso criar um nó filho a partir de qualquer atividade
- [ ] A hierarquia não tem limite fixo de profundidade
- [ ] A árvore reflete a decomposição imediatamente após a criação
