# ST-01 — Persistir atividade como arquivo

| Campo | Valor |
|-------|-------|
| Épico | EP-04 — Explorar |
| Status | draft |
| Persona | Qualquer usuário do Plans |

## História

Como **usuário do Plans**, quero que **toda atividade exista como arquivo na seção Explorar**, para **ter uma representação persistente única do trabalho**.

## Critérios de aceite

- [ ] Ao criar card, tarefa ou nó, um arquivo correspondente aparece no Explorar
- [ ] Remover ou alterar a unidade reflete no arquivo correspondente
