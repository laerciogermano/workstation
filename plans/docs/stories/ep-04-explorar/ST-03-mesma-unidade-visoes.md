# ST-03 — Mesma unidade entre visões

| Campo | Valor |
|-------|-------|
| Épico | EP-04 — Explorar |
| Status | draft |
| Persona | Qualquer usuário do Plans |

## História

Como **usuário do Plans**, quero **abrir no Explorar a mesma unidade que vejo no board, Gantt ou árvore**, para **não haver divergência entre card, tarefa, nó e arquivo**.

## Critérios de aceite

- [ ] Um card no board corresponde ao mesmo arquivo no Explorar
- [ ] Uma tarefa no Gantt corresponde ao mesmo arquivo no Explorar
- [ ] Um nó na árvore corresponde ao mesmo arquivo no Explorar
