# RolêGo — logo pincel + Go

18 possibilidades juntando o **ROLÊ em pincel** de [`../estilo-viva-o-role/combinacoes/`](../estilo-viva-o-role/combinacoes/README.md) com o **Go** (símbolo gomoso) da logo atual. Os dois desenhos são os originais; mudam posição, escala, giro e acabamento. Nada aprovado.

| Arquivo | O que é |
|---|---|
| [`possibilidades-rolego-pincel-go.pdf`](possibilidades-rolego-pincel-go.pdf) · `.html` | 14 págs.: as 18 no roxo, preto e claro; detalhe de duas em duas; 03–05 em 8 paletas; tamanho pequeno |
| `svg/` | `NN-nome-{roxo,preto,claro}.svg`, fundo transparente |
| `_build.py` | Gerador (`OPCOES`, `TEMAS`, `COMBOS`) |

Pendência: o lettering foi vetorizado de uma arte de origem não confirmada ([detalhes](../estilo-viva-o-role/README.md)). Antes de virar logo, confirmar o direito de uso ou redesenhar.

```bash
cd role-go/marca/logo-pincel-go && python3 -B _build.py
```
