## Como usar no setup

| Uso | Campo / fluxo |
|---|---|
| Empresa atual (signup) | `company` → default ConectMax; pode variar por vendedor |
| Experiência prévia | cargo + empresa do CSV (`nome`) em setup de Experience |
| Persona KAM MRO | preferir `c08`–`c14` (Ferramentas Gerais, Nortel, Anhanguera…) |
| Persona indiretos / inside | preferir `ref02`, `c01`–`c07` (BR Supply, Onfinity, Viasupri, Kalunga…) |

Evitar misturar marcas de outro setor (telecom “ConnectMax Fibra”, varejo puro sem B2B).
